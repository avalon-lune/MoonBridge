# 月渡 0.2.1 验收指引

正式应用位于项目根目录的 `MoonBridge.app`。本轮更新保留现有游戏位置、Windows 运行底层、主程序选择、汉化修复和存档环境。

## 你可以直接检查

1. **游戏库视觉**：粉蓝白底色，三人水彩横幅、独立侧栏插画、三种默认封面。横幅和人物完整适配，不把同一幅画裁成多个区域。已匹配的真实游戏封面继续显示。
2. **本地主页**：点击游戏，查看开发商、发行信息、中文概况及来源；“整理中文概况”可依据来源事实重新组织介绍。来源原文折叠保留。
3. **千咲**：打开“和千咲聊聊”。右上角为参考官方形象制作的手绘 Q 版头像，角色定位是游戏库管理员。
4. **共享记忆**：输入“请记住：我喜欢粉蓝白水彩风格”。换另一款游戏或重新打开应用后，可在“管理记忆”中找到这条事项。聊天历史默认折叠，新一轮单独显示。
5. **模型与 API**：设置中可修改 HTTPS API 地址、Key、模型与推理强度；模型可从接口列表选择，也可手动输入。询问“你是什么模型”会按实际配置直接回答。
6. **原有运行设置**：游戏主页的“运行设置”保留主程序、语言区域、全屏/虚拟桌面、补丁和日志。开始游戏后按自己原有方式加载进度即可。

## 已完成的检查

- 32 项原有导入与运行回归，包括真实 Win32 / Win64 测试程序执行。
- 16 项资料与 API 离线回归。
- 12 项共享 SQLite 记忆回归，包括跨游戏中文召回、重开持久化、旧记录幂等合并和事务回退。
- 实际 API 连接、带来源问答、模型列表与跨游戏记忆回复测试。
- 视觉更新前后 14 个功能源文件一致，游戏和运行前缀共 7,782 个文件的大小、修改时间和链接目标一致，游戏索引 SHA-256 一致。

具体证据保存在项目内 `metadata/v02-validation.json` 和 `metadata/v021-validation.json`。这些记录、游戏、存档、缓存、聊天和密钥不发布到代码仓库。
