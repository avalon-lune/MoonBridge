# 验证记录 / 2026-11-03

本页区分源码检查、实际 Windows 程序执行与用户游玩确认。没有宣称通用兼容率。

## 环境

本地实测：Apple M5、24 GB、macOS 27.0.1、Swift 6.4 Command Line Tools。GUI 最低部署目标是 macOS 14，不代表已在全部受支持系统上回归。

## 自动与 GUI 检查

当前核心 / 集成检查覆盖以下项目。发布前在独立副本重新执行，摘要见 [发布记录](../metadata/publication.json)。

- release 编译与本地 ad-hoc 签名。
- 目录穿越拦截、Unicode 路径、假 EXE 拒绝、PE32 与 PE32+ 识别。
- ZIP 完整导入、中文补丁发现、同名原文件备份、新启动器重新扫描。
- 游戏库原子保存和读取、已准备环境复用。
- 搬家后修复缓存前缀的旧绝对 G: 映射，包含带空格的新路径。
- `--runtime` 真正执行本项目生成的 Win32 / Win64 进程，预期退出码均为 37。
- GUI 自检包导入、主程序 / 区域 / 显示设置展示，真实界面截图见 README。

源码位于 `tests/Check` 与 `scripts/make-fixtures.py`。本机日志含工作路径，不发布到仓库；公开记录只保留摘要。

早期还检查过 GStreamer 的 H.264 / WMV3 解码器加载和合成视频链路。这不等于所有游戏的 DirectShow / Media Foundation 或 OP / ED 均正常。

## 仍需逐款验证

独占全屏、Retina 输入坐标、特殊字体、DRM、私有 DLL、依赖安装器、视频、完整通关以及旧存档兼容。7Z / RAR 共用同一 7-Zip 解压路径；个别包解压通过不等于各种分卷、多层包装均由 GUI 自动处理。

当前没有 ARM Wine / FEX 后端，也没有 macOS 28 的运行通过结论。

## 复现

```sh
bash scripts/build.sh
./build/swift/release/MoonBridgeCheck "$PWD" --runtime
```

测试只使用新建的 `tests/work-*`。源码仓库不包含测试过程中生成的 Windows 前缀、私人日志和商业游戏存档。
